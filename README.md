I’m Frank Peterlein, an IT and AI practitioner in Berlin. I use public
repositories as working laboratories for systems that generate behavior,
preserve viability, expose hidden structure, or fail in instructive ways.

Selected work:

- [`systems-and-intelligence`](https://github.com/frnkptrln/systems-and-intelligence) — the active flagship: emergence, inverse reconstruction, optimization, and viability constraints.
- [`the-weaving-void`](https://github.com/frnkptrln/the-weaving-void) — executable dual-reading artifacts: surface, reader, thread, runtime, trace.
- [`the-weaving-sound`](https://github.com/frnkptrln/the-weaving-sound) — an anthology of generative SuperCollider pieces and shared sound engines.
- [`the-crawling-void`](https://github.com/frnkptrln/the-crawling-void) — a defensive-alpha CTI/OSINT toolkit with explicit scope and redaction boundaries.
- [`berlin-transit-friction`](https://github.com/frnkptrln/berlin-transit-friction) — a bounded accessibility experiment rebuilt from an invalid general prototype.

The curated path is at [frnkptrln.github.io](https://frnkptrln.github.io). Not
every repository is active; statuses such as alpha, bounded, paused, and
archived are intentional.
